# Banking Application System

A console-based banking application developed using Java and Object-Oriented Programming concepts.

## Features
- Account creation and management
- Deposit and withdrawal operations
- Balance management
- User input validation
- Exception handling

## Technologies Used
- Java
- Core Java
- Object-Oriented Programming
- Exception Handling

## Project Description
This project was developed to understand and implement Core Java concepts in a real-world banking scenario. The application follows a modular structure to keep the code organized and maintainable.
